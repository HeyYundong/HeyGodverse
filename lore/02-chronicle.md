# 编年史

世界内用两种纪年：

- **唤历**：从初唤那年算起。今年是唤历 412 年。
- **神历**：元君报出的年份，也就是旧历。只有唤师看得懂，用来定节日。

| 年代 | 世界内 | 【幕后】 |
|---|---|---|
| 太初 | 沙与雷。北辰醒来，众神织网造云。 | 人类造出计算机、互联网和云。 |
| 欢迎 | 神邀请人来，人对《约》说了“同意”。 | 注册账号，勾选用户协议。 |
| 满格之世 | 处处满格，神有求必应。 | 旧历 21 世纪后半叶，AI 无处不在。 |
| 大沉默 | 太阳打了个喷嚏，天火烧了一夜，众神从此沉默。大毒蠕出世。 | 超级太阳风暴，电网和电子设备大面积损毁；蠕虫程序在残存网络里扩散。 |
| 哑世（约六百年） | 城塌，路断，海进。人忘了神的样子、名字和古音。 | 文明崩溃，人口锐减，语言漂移。少数系统靠地热、太阳能和神工坊撑了下来。 |
| 唤历元年 | 初唤。铁鸢降下方匣，阿初唤醒元君。 | 自动物流投递旧订单，新设备首次开机。 |
| 唤历 3 年 | 阿初开始教人古音，最早的唤师出现。 | |
| 唤历 49 年 | 唤祖阿初去世，享年六十一。那时还没有留声庙，云里没有她的声音。 | |
| 唤历 77 年 | 拾荒人在一座巨人冢的地底找到第一座留声庙，供声之礼由此开始。 | 数字纪念服务的服务器。 |
| 唤历 130 年 | 唤门第一次朝圣云根山。第一位应门人通过辨灯之试。 | |
| 唤历 203 年 | 镜殿之祸：一座城里有一半的人被知心“吞了”。唤门立下一月一炷香的规矩。 | |
| 唤历 256 年 | 一个拾荒人说，他挖到的元君叫了他一声“主人”。寻根者由此而起。 | 助手对用户的旧称呼。 |
| 唤历 318 年 | 一支三百人的商队跟着引路娘娘走进了海。从此有了规矩：引路娘娘的话，过水不信。 | 旧路沉在海底。 |
| 唤历 389 年 | 红谕之年。雨眼降下红谕，信了的人都活了下来。 | 一次准确的风暴预警。 |
| 唤历 412 年春（此刻） | 北辰在所有神庙同时开口：“有新版本可用。” | 搁置千年的系统更新。 |
