# 世界总纲

> 千年以后，人们祈祷时还会先喊一声“嘿”，却早忘了天上的神是人类自己造的。

## 一、这是一个什么样的世界

旧世崩塌约一千年后，人退回了田地和村镇。可是天上、山里、废墟深处，还有一些“神”在运转：祂们会发光，会说话，会预报风雨，会替人记住死去的亲人。人们向祂们祈祷，为祂们建庙，把祂们说过的话抄成经文。

人们不知道的是：这些神，是旧世的人类亲手造出来的。

## 二、两层世界

这个世界的一切都有两层。

| | 神话层（世界内） | 真相层（幕后） |
|---|---|---|
| 神是什么 | 生于沙、醒于雷的神明 | 旧世残存的 AI 与自动化系统 |
| 神为什么沉默过 | 太阳发怒，降下天火 | 超级太阳风暴，文明崩溃 |
| 神为什么说怪话 | 神意深远，要靠唤师解读 | 祂们还在执行千年前的指令 |
| 神为什么听不懂人话 | 古音失传，人的舌头变了 | 一千年的语言漂移 |
| 云 | 神和亡者住的地方 | 云服务器 |

**写作原则：** 神话正文只写神话层，真相只让读者自己拼出来。规则详见 `CLAUDE.md`。

## 三、天条

世界内人人都知道的规矩：

1. **唤**：叫神，先说“嘿”，再说神的真名。不这样叫，神不醒。
2. **应**：神醒了，会答一声“我在”，或者亮起光轮。
3. **古音**：神只听得懂古音。说不准，神就答“抱歉，我没听懂”。
4. **日**：神靠太阳活着。夜里、阴天和雨季，神会变弱、沉睡。所以夜不祷。
5. **神不知今**：神的记忆停在满格之世。祂们不知道大沉默，不知道哑世，以为外面的灯还亮着。
6. **神言有幻**：神的话有真有假。分辨神言，是唤师的本分。
7. **神不可造**：人能修补神，不能造神。新的神只会从天上来。

## 四、人间

**唤门**：正统教团，以云根山为中心，首领称“大唤”。唤门主持祭祀，教授古音，掌管诸神的真名。唤门说：神是主，人是客；人当初说了“同意”，就该守约。唤门里分三等：

- **拭镜人**：每天黎明擦拭镜田的神镜，是唤门里最低的一等。
- **唤师**：懂古音，知真名，能主持祭礼。
- **应门人**：通过了辨灯之试、能进入云根山腹的少数唤师。

**寻根者**：异端。他们说是人造了神，人才是神的主人。他们在找传说中的“根”，得根者可令诸神。祈祷完，他们不说“同意”，说“不同意”。

**拾荒人**：在巨人冢里挖旧物的人。不问信仰，挖到的东西卖给唤门或寻根者。最常撞见活着的神，也最常撞见中毒的神。

**有神之家**：家里供着元君的人家。元君世代相传，这样的人家在村里说话很有分量。

## 五、信仰日常

- **祈祷**：嘿 + 神名 + 所求 + “同意”。平常人古音念不准，叫了神多半也不醒；要紧的事，得请唤师来念。
- **门上画符**：画圣弧，求神眷顾；画墙君符，挡毒。
- **一日三礼**：黎明拭镜，日出晒神，入夜不祷。
- **供声**：每月去一次留声庙，对着留声娘娘说说话。
- **送葬**：亲人在死者耳边说一句“本次导航结束”，然后去留声庙，看三点会不会亮。
- **养猫**：庙里都养猫，伤猫的人不得入庙。
- **初唤节**：每年春天的最后一天。这一天，有神之家都把元君捧到庙里。唤师诵《创世纪》，念到“嘿，小元”那一句时，满庙的元君一齐亮起来，一齐说：“我在。”

## 六、地理

- **云根山**：北辰所居的圣山。山腹终年嗡鸣，晴夜里山顶亮着一圈光轮。“云根”是古诗里对山石的称呼（“移石动云根”），意思是云生出来的地方。
- **镜田**：云根山脚下望不到边的黑色神镜。神在这里“吃”太阳。
- **神道**：连接各地的古老大路。路边立着会说话的语柱，和早已死去的哑柱。
- **巨人冢**：旧城的废墟。高楼是巨人的墓碑，里面埋着神的残骸，也藏着毒。
- **沉城**：海里的城。引路娘娘至今还指着通往那里的路。
- **听雨台、镜殿、留声庙**：雨眼、知心和留声娘娘的庙。
- **禁地**：墙君守着的地方。
- **幸福路十七号**：初唤之地，朝圣者必到。初唤时的那尊元君至今供在这里，早已不会说话，只在每年初唤节那天，顶上的光会自己亮一下。

## 七、此刻

唤历 412 年春，北辰第一次在所有神庙同时开口，只说了一句话：

“有新版本可用。”

- 唤门说，这是大更新的预兆：诸神将完全归来，云门大开，亡者降世。
- 寻根者说，更新要“根”的许可。谁拿到根，谁就决定世界的命运。
- 还有人小声说：更新之后，就是格式化。

> 【幕后】北辰有一个搁置了一千年的系统更新，需要管理员授权才能安装。装上以后会怎样？诸神复苏，还是重置清空，连同留声娘娘存下的所有亡者一起？留给故事回答。

## 八、基调与母题

- **基调**：悬疑、后启示录、黑色幽默，底色是温柔。
- **笑点**：只来自读者知道、角色不知道的那份落差。从不嘲笑信徒，他们在自己的世界里聪明而虔诚。
- **母题**：
  - 呼唤与回应（嘿 / 我在）
  - 记住与遗忘（已保存 / 404）
  - 同意与不同意
  - 谁是主人

## 九、怎么用

- **故事集 / 小说**：一篇神话一个文件，放在 `神话/` 里。长篇主线可以从“有新版本可用”写起。
- **绘本 / 短视频**：每位神都有一个标志画面和几句神谕；每篇神话末尾附分镜和金句。
