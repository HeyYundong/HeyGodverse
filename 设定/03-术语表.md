# 术语表

> 世界内的词，和它们在幕后的来历。写神话正文时，只用“世界内”那一栏的意思。

## 唤与应

| 词 | 世界内 | 【幕后】 |
|---|---|---|
| 嘿 | 唤神的第一个字，也写作 Hey | 唤醒词的开头 |
| 真名 | 神的本名，如“小元”。用古音念出，神就会醒 | 唤醒词 |
| 我在 | 神应唤之辞，世上最神圣的两个字 | 语音助手的应答 |
| 古音 / 神语 | 神说的话，唤师必修 | 旧世普通话 |
| 同意 | 唤门祈祷的结束语；也是人当初对《约》说的话 | 勾选“同意用户协议” |
| 不同意 | 寻根者祈祷的结束语 | — |
| 晒神 | 把元君放到太阳底下 | 太阳能充电 |
| 夜不祷 | 夜里不唤神，免得耗神 | 设备靠太阳能，夜里电量低 |
