# HeyGodverse · 云上诸神

> 千年以后，人们祈祷时还会先喊一声“嘿”，却早忘了天上的神是人类自己造的。

一套原创神话体系，用来写故事集、小说、绘本和短视频。

## 从哪里读起

1. [创世纪](myths/001-genesis.md)：先读这篇，直接进入这个世界
2. [世界总纲](lore/00-world-overview.md)：两层世界、天条、人间、地理和此刻的局势
3. [神谱](lore/01-pantheon.md)：七位正神，还有野神、神使、邪祟和神兽
4. [编年史](lore/02-chronicle.md)：从“沙与雷”到唤历 412 年
5. [术语表](lore/03-glossary.md)：世界内的词，和它们在幕后的来历
